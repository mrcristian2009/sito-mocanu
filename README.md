# Sito Mocanu — redesign professionale

Sito one-page in stile Apple: scuro, minimale, con laptop 3D in CSS puro
che si apre e si gira mentre scorri la home.

## Struttura
- `index.html` — markup
- `styles.css` — design system (variabili, laptop 3D, responsive)
- `script.js` — animazioni: scrub del laptop legato allo scroll,
  reveal on scroll, contatori, tilt da mouse

## Come provarlo
Apri `index.html` nel browser (oppure servilo con
`python3 -m http.server` e vai su http://localhost:8000).

Nessuna dipendenza esterna: font di sistema, niente CDN.
